# CANBUS Monitor

AI-assisted CAN FD development platform based on NUCLEO-C542RC.

## Status

Stage 0 — Harness bootstrap

## Components

- STM32C542RC firmware
- STM32 HAL
- FreeRTOS
- FDCAN
- Python Qt6 desktop tool
- Cppcheck
- Ceedling
- Automated reports

## Quick Start

python tools.py doctor
python tools.py build
python tools.py check
